## 概要

- `NicheLibrary::UInt128` は 128 bit 符号なし整数型である。
- `NicheLibrary::Int128` は 128 bit 符号付き整数型である。
- GCC 拡張には依存しない。
- `std::numeric_limits` に対応している。
- 10 進表記でストリーム入出力できる。
- 主に、他のライブラリの内部計算で用いる。
- 組み込み整数型より低速であることに注意する。

## 使い方

- `NicheLibrary::UInt128`
  - 128 bit 符号なし整数型である。
  - 整数型から構築できる。
  - 整数型へ明示変換できる。
  - `long double` へ明示変換できる。
  - 加算、減算、乗算、除算、剰余、比較を使用できる。
  - 10 進表記でストリーム入出力できる。
  - 備考: 負の符号付き整数から構築すると、その整数を $2^{128}$ を法とする剰余で表す。
  - 前提: ストリームから入力する整数は `NicheLibrary::UInt128` の範囲に収まる。
  - 前提: 除算と剰余では、除数が $0$ でない。
  - 備考: 加算、減算、乗算の結果は $2^{128}$ を法として表す。

- `NicheLibrary::Int128`
  - 128 bit 符号付き整数型である。
  - 整数型から構築できる。
  - 整数型へ明示変換できる。
  - `long double` へ明示変換できる。
  - 加算、減算、乗算、除算、剰余、比較を使用できる。
  - 10 進表記でストリーム入出力できる。
  - 前提: ストリームから入力する整数は `NicheLibrary::Int128` の範囲に収まる。
  - 前提: 演算結果が `NicheLibrary::Int128` の範囲に収まる。
  - 前提: 除算と剰余では、除数が $0$ でない。
  - 前提: 型の最小値を $m$ として、 $m / -1$ および $m \bmod -1$ を行わない。

- `NicheLibrary::UInt128::div_mod(lhs, rhs, quotient, remainder)`
  - `lhs` を `rhs` で割った商と余りを求める。
  - 返り値を持たず、`quotient` に商を、`remainder` に余りを書き込む。
  - 前提: `rhs` は $0$ でない。
  - 前提: `quotient` と `remainder` は異なるオブジェクトを参照する。
  - 備考: `lhs` を $L$ 、`rhs` を $R$ 、`quotient` を $q$ 、`remainder` を $r$ とおく。 $L=qR+r$ かつ $0\le r<R$ が成り立つ。
  - 備考: 呼び出し時に、同じオブジェクトを `lhs` と `rhs` の両方へ渡してもよい。
  - 備考: `quotient` または `remainder` と、`lhs` または `rhs` に同じオブジェクトを渡してもよい。

- `NicheLibrary::Int128::div_mod(lhs, rhs, quotient, remainder)`
  - `lhs` を `rhs` で割った商と余りを求める。
  - 返り値を持たず、`quotient` に商を、`remainder` に余りを書き込む。
  - 前提: `rhs` は $0$ でない。
  - 前提: `lhs` が型の最小値でないか、または `rhs` が $-1$ でない。
  - 前提: `quotient` と `remainder` は異なるオブジェクトを参照する。
  - 備考: 商は $0$ 方向へ丸める。
  - 備考: `lhs` を $L$ 、`rhs` を $R$ 、`quotient` を $q$ 、`remainder` を $r$ とおく。 $L=qR+r$ が成り立つ。
  - 備考: `remainder` が $0$ でない場合、`remainder` の符号は `lhs` の符号と一致する。
  - 備考: 呼び出し時に、同じオブジェクトを `lhs` と `rhs` の両方へ渡してもよい。
  - 備考: `quotient` または `remainder` と、`lhs` または `rhs` に同じオブジェクトを渡してもよい。

- `NicheLibrary::UInt128::from_words(high, low)`
  - 上位 64 bit が `high`、下位 64 bit が `low` である値を返す。

- `NicheLibrary::Int128::from_words(high, low)`
  - 2 の補数表現で、上位 64 bit が `high`、下位 64 bit が `low` である値を返す。

- `NicheLibrary::UInt128::high()`, `NicheLibrary::UInt128::low()`
  - それぞれ上位 64 bit、下位 64 bit を `std::uint64_t` 型で返す。

- `NicheLibrary::Int128::high()`, `NicheLibrary::Int128::low()`
  - 2 の補数表現の上位 64 bit、下位 64 bit をそれぞれ `std::uint64_t` 型で返す。

- `NicheLibrary::Int128::is_negative()`
  - 値が負ならば、`true` を返す。

- `std::numeric_limits<NicheLibrary::UInt128>`, `std::numeric_limits<NicheLibrary::Int128>`
  - 各整数型の最小値、最大値、符号の有無、有効桁数などを取得できる。

## 計算量

- 加算、減算、乗算、比較: 定数回の 64 bit 整数演算を行う。
- 除算、剰余、`div_mod`: 32 bit の語を用いた固定長の長除算であり、最大で 4 桁の商を求める。
- 10 進表記のストリーム入出力: 9 桁ごとの処理を最大 5 回行う。
